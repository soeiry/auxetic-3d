# 논문 기반 general 3D re-entrant CAD 모델

Ghavidelnia et al. (2021), *Idealized 3D Auxetic Mechanical Metamaterial: An Analytical, Numerical, and Experimental Study*, Materials 14, 993, DOI: 10.3390/ma14040993.
원문: https://pmc.ncbi.nlm.nih.gov/articles/PMC7923447/

사용자가 제공한 본문 PDF의 Fig. 2(a,b), §2.1.1, 식 (1), §2.2, §3.1과 보충 PDF의 Fig. S1–S4를 직접 확인했다. `reference/`의 텍스트와 그림은 해당 PDF에서 추출한 검토 자료다. 아래 모델은 **general** 형이며 Type III를 제거한 lightened 형이 아니다.

## 결과 파일과 좌표계

- `outputs/unit_cell.step`, `outputs/unit_cell.stl`: 단위 셀 1개.
- `outputs/lattice_2x2x2.step`, `outputs/lattice_2x2x2.stl`: x, y, z 방향 각각 2회 반복한 연결 격자.
- `outputs/*_views.png`: 등각도·정면·측면·윗면을 모은 그림. 개별 PNG도 포함.
- `outputs/*_nodes.csv`, `outputs/*_struts.csv`: 절점 좌표와 부재 연결, 유형, 길이, 반지름.
- `outputs/parameters.json`, `outputs/design_variables.csv`: 수치 입력 및 설계변수 표.
- `outputs/validation.json`: 그래프, BRep, STEP 재읽기, STL 검사 결과.
- `model_auxetic.py`: 생성·검사·미리보기 작성 코드.

길이 단위는 모두 **mm**, 각도 입력은 degree다. y를 향후 인장 방향, x를 폭, z를 두께 방향으로 정했다. 단위 셀 중심은 (0,0,0), 외곽 범위는 각 축 -38.55~38.55 mm다. 반복 격자 중심들은 (iL,jL,kL)에 위치하며 i,j,k=0,1이다. 따라서 격자 범위는 -38.55~115.65 mm이고 각 변 길이는 154.2 mm다.

STEP에 mm 단위를 기록한다. STL은 단위 정보를 담지 않으므로 가져오는 프로그램에서 mm로 해석해야 한다. 정면은 +z에서 본 XY, 측면은 +x에서 본 ZY, 윗면은 +y에서 본 XZ 투영이다. 미리보기 눈금의 원점은 그림 배치를 위해 각 모델 외곽 중심으로 옮겼으며 CAD 좌표는 변경하지 않았다.

길이 l₁,l₂,l₃는 모두 절점 중심 간 길이다. 논문의 유효 부재 길이(접합부 중첩을 제외한 길이)로 바꾸지 않았다. 논문 그림만으로 제조 시편의 필렛 반지름 등 세부 접합면을 확정할 수 없어, 원형 단면 부재를 중심선 끝점까지 만든 뒤 결합했다. 따라서 **논문의 중심선 배치·연결·기본 치수 조건을 재현한 모델**이며 원저자의 SolidWorks 파일과 완전히 동일한 접합면이라고 주장하지 않는다.

공칭 μ=0.10은 식 (1)처럼 개별 원기둥 체적을 더한 값이다. Boolean union에서 접합부 중복 체적을 한 번만 세면 실제 체적비는 **0.08352436**이다. 실제 CAD 체적비가 0.10인 시편을 맞추려면 반지름을 추가 조정해야 하며, 여기서는 그러한 밀도 보정을 적용하지 않았다.

논문 실험 재료는 **PLA**다. 이 모델에는 TPU의 물성, 프린터 수축률, 필렛, 프린팅 보정, 어깨 곡면 또는 슬리브 형상을 적용하지 않았다. 77.1 mm 셀은 논문 크기를 재현하기 위한 것이며 어깨 슬리브에 적합한 최종 크기로 선정된 값이 아니다.

## Fig. 2와 대응하는 입체 연결 관계

주 큐브 꼭짓점 8개는 D=(±b,±b,±b)이다. 각 축의 양·음 방향에 다음 절점을 만든다.

1. 면 안쪽 절점 I: ±a·eₓ, ±a·eᵧ, ±a·e_z. 논문의 B₁,B₂ 및 E₁…E₄에 해당한다.
2. 외부 연결 끝점 T: ±h·eₓ, ±h·eᵧ, ±h·e_z. 논문의 A₁,A₂ 및 F₁…F₄에 해당한다.
3. 주 큐브 모서리의 움푹 들어간 중간 절점 M: (0,±c,±c)의 좌표 순열 12개. 논문의 C₁…C₈ 및 G₁…G₄에 해당한다.

코드는 투영 그림의 번호 대신 축·부호 기반 이름을 사용한다. D는 8개 꼭짓점, I는 면 안쪽, T는 연결 끝점, M은 모서리 중간 절점이다. CSV의 이름은 이 규칙으로 읽는다.

| 종류 | 연결 | 수 |
|---|---|---:|
| Type I | 같은 축·부호의 I–T | 6 |
| Type II | 각 I에서 해당 면의 D 네 곳 | 6×4=24 |
| Type III | 각 모서리의 D 두 곳에서 해당 M으로 | 12×2=24 |

총 32절점, 54부재다. D의 차수는 6, I는 5, M은 2, T는 1이다. 중앙 원점에 절점이나 연결 부재를 추가하지 않았다. 정면 투영에서 교차하는 선이 모두 실제 접합을 뜻하지는 않는다. 회색 면으로 표현된 Fig. 2의 면을 판재로 만들지도 않았다.

모서리 중간 절점은 해당 모서리의 중점에서 큐브 중심 쪽 대칭 이등분 방향으로 들어간다. Fig. 2/S2의 대칭을 사용하면, 예를 들어 (b,b,b)→(0,c,c)의 두 비축 성분이 같고, Type III와 원래 큐브 모서리 사이 각도가 φ가 된다. 이 좌표는 본문 식 (27)의 Type II–III 사이 각도 관계와도 일치한다.

기하 관계는 다음과 같다.

```text
l₂ cosθ = √2 b           l₃ cosφ = b
a = b − l₂ sinθ = b(1 − √2 tanθ)
c = b − l₃ sinφ/√2 = b(1 − tanφ/√2)
h = a + l₁
L = 2h = 2(l₁ + l₃ cosφ − l₂ sinθ)

동일 반지름일 때:
r = √[ μ L³ / {π(6l₁ + 24l₂ + 24l₃)} ]
```

이 관계로부터 모든 좌표와 종속 길이를 계산한다. 길이, 각도, 셀 크기를 서로 모순되게 독립 지정하지 않는다.

## 반복 경계와 형상 검사

반복 이동량은 (L,0,0), (0,L,0), (0,0,L)이다. 인접한 두 셀의 Type I 외부 끝점 T가 정확히 일치한다. 두 원기둥의 축 방향은 서로 반대이고 원형 단면 전체가 일치한다. 별도의 공중 브리지나 유격을 추가하지 않았다. Boolean union은 공유 면을 제거하고 하나의 솔리드로 만든다.

2×2×2에는 x, y, z 방향별 4개씩 총 **12개의 내부 경계 접합부**가 있다. 결합 그래프는 244절점, 432부재이며 연결 성분은 1개다. 외곽에는 24개의 끝점이 남는다.

현재 기본 출력에서 확인한 결과:

| STEP 재읽기 유효성 / 솔리드 수 | 통과 / 1 | 통과 / 1 |

간섭 검사는 각 유한 중심선의 최소 거리에서 두 반지름을 빼는 방법이다. 원기둥보다 큰 캡슐 외피가 서로 분리됨을 확인하므로 양수인 위 간격은 비접합 부재 간 비간섭의 보수적 증거다. 공유 절점이 있는 부재는 의도된 접합이므로 이 검사에서 제외하고, 최종 BRep가 유효한 단일 솔리드인지 검사한다. 매개변수를 바꿔 캡슐들이 닿거나 겹치면, 실제 원기둥 간섭 여부가 불확실하더라도 생성기가 중단하도록 보수적으로 설정했다.

반복 격자 체적 / (8 × 단위 셀 체적)은 0.9999999999999998이다. 경계의 면 접합 외에 이웃 셀끼리 체적이 겹치거나 잘려 나가지 않았음을 확인했다. 검사 허용치는 코드에 명시되어 있고, 오류가 있으면 예외로 종료한다.

ANSYS 자체는 실행하지 않았다. STEP 재읽기와 솔리드 유효성은 CadQuery/Open CASCADE에서 검사했다. ANSYS에서 이 STEP을 가져와 하나의 solid body인지 확인하고 재료·메시·하중을 설정할 수 있지만, ANSYS 가져오기 및 해석 성공을 검증한 것은 아니다.

## 재생성 및 치수 변경

현재 환경은 Python 3.12.14, CadQuery 2.7.0, OCP 7.8.1.1을 사용한다. 이미 설치된 도구로 실제 생성했다. 별도 환경에서는 Python 3.12 가상환경에서 `python -m pip install -r requirements-cad.txt`로 직접 의존성을 설치할 수 있다. 후속 환경에서의 설치는 별도로 실행 검증하지 않았다.

```bash
cd /workspace/auxetic-3d
python3 model_auxetic.py
```

기본 실행은 `outputs/`를 다시 작성한다. 기존 결과를 보존하려면 다른 `--output` 디렉터리를 지정한다. 파일에는 형상이 들어 있고 코드 수정 없이도 인수로 치수를 바꿀 수 있다.

```bash
# 셀 크기 20 mm로 축소: 각도, l₁/b, 공칭 μ 유지
python3 model_auxetic.py --cell-size 20 --output outputs_scaled20

# 각도, 부재별 반지름, 반복 개수 변경
# 이 명령의 형상/STEP/STL 검사는 실제로 별도 임시 디렉터리에서 통과했다.
python3 model_auxetic.py --cell-size 20 --theta 20 --phi 25 \
  --radii 0.6 0.65 0.7 --repeat 2 1 1 --output outputs_variant --no-preview

# b와 l₁을 직접 지정; 나머지 길이와 L은 기하 관계로 계산
python3 model_auxetic.py --b 10 --l1 10 --radius 1 --output outputs_b10

# l₂를 기준 길이로 선택 (또는 --l3 사용)
python3 model_auxetic.py --l2 20 --l1-ratio 1 --mu 0.10 --output outputs_l2_20
```

`--cell-size`, `--b`, `--l2`, `--l3` 중 하나만 선택한다. `--l1`을 쓰면 Type I 길이를 직접 지정하고, 그렇지 않으면 `--l1-ratio`×b를 사용한다. `--radius`는 모든 부재에 동일 반지름, `--radii r1 r2 r3`는 종류별 반지름을 지정한다. 직접 반지름을 주면 μ는 그 반지름으로 다시 계산된다. 반지름을 생략하면 μ로부터 계산한다. `--repeat NX NY NZ`는 반복 수다.

이 생성기는 양의 re-entrant 각도와 면 안쪽 절점이 중심을 넘지 않는 범위(0<θ<35.264389°, 0<φ<54.735610°)를 대상으로 한다. 외곽이 셀 경계를 침범할 만큼 반지름이 크거나 l₁이 짧으면 중단한다. 이는 논문의 모든 양·음 각도 일반화를 구현한 도구가 아니라 이번 기본형을 안정적으로 변경하기 위한 범위 제한이다. 크기를 줄이면서 반지름을 고정하면 간섭이 발생할 수 있으므로 모든 변경 출력에서도 동일한 검사를 실행한다.

## 해석 범위

완료한 작업은 형상 생성과 기하학적 검사다. **y 인장 시 x 폭 및 z 두께 증가, TPU 대변형 거동, 특정 변형률에서의 잠김, 피로, 어깨 슬리브 착용 성능은 해석하거나 실험하지 않았다.** 기본 셀의 대칭과 re-entrant 연결만으로 이러한 성능을 검증했다고 볼 수 없다. 필요한 후속 작업은 TPU 물성 및 프린팅 조건 선정, 실제 경계조건에서의 비선형 해석, 접촉·자기접촉과 대변형 검토다.
